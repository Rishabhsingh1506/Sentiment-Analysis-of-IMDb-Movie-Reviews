# Dataset

Put the dataset here as:

`imdb_reviews_1000.csv`

Required columns:

```text
review,sentiment
```

Optional columns:

```text
rating,genre
```

Example:

```csv
review,sentiment,rating,genre
"This movie was excellent...",positive,9,Drama
"The story was boring...",negative,4,Comedy
```

The repository does not include the raw IMDb reviews. Download/use a dataset from a legitimate source and follow its license/terms.
